🚀 About Me

Hi, I’m David Aryasetia, a Backend Developer and Database Administrator with hands-on experience in designing and managing scalable backend systems. I specialize in Laravel, Python Framework (Flask, Django), RESTful APIs, and database management using MySQL, PostgreSQL, and Oracle.

My expertise includes:

  • Backend Development with PHP, Python, Javascript, Laravel, Flask-Restx, Django, using Object-Oriented Programming (OOP)
  • Rest API & Microservices Architecture
  • Database Schema Design
  • PL/SQL Programming & Query Optimization
  • Cloud Infrastructure Deployment using OCI (Oracle Cloud Infrastructure) Leveraging, Nginx, PM2, Gunicorn, NetData, CI/CD(Jenkins), Portainer, Docker, SSL (Let's Enscrypt), Kafka, Grafana, Prometheus, Node-exporter, Cadvisor, Zabbix, Elastic Stack (Elastic, Logstash, Kibana)
  • Design System using UML, Sequence Diagram, Flow Chart, and Use case Diagram
